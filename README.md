# Jahan's website

Games, messages and photos by Jahan.

## Adding things

Open the editor at **`/admin.html`** on the website (for example `https://username.github.io/admin.html`) and bookmark it.

| Tab | What it does |
|---|---|
| ✍️ Message | Write news, with an optional picture |
| 📷 Photos | Add one or more pictures with captions |
| 🎮 Game | Upload a game (one `.html` file, or all the files from a Godot web export) |
| 🙂 About me | Change the website name, tagline, picture and About me text |
| 🗂️ Manage | Edit messages, or delete games, messages and photos |

Changes show up on the website about a minute after you publish.

The first time, the editor asks for a GitHub **token**: a key that lets it publish. The steps to make one are on the editor's Connect screen. Keep the token private, like a password.

## What's in here

| File or folder | What it is |
|---|---|
| `index.html` | The website's home page |
| `admin.html` | The editor |
| `content/data.js` | Everything on the website: profile, games, messages and photo list. The editor updates it. |
| `games/` | The games |
| `photos/` | Pictures (created by the editor) |
