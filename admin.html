✏️ Website editor

Connect to GitHub

To publish to your website, the editor needs a GitHub key called a token. A grown-up sets this up once.

How do I get a token?
  1. Sign in to GitHub with the website's account.
  2. Open New fine-grained token (Settings → Developer settings → Personal access tokens → Fine-grained tokens).
  3. Token name: Website editor. Expiration: pick a date up to a year away.
  4. Repository access: Only select repositories → choose the website repository.
  5. Permissions: add Contents and set it to Read and write.
  6. Click Generate token, copy it, and paste it above.

Treat the token like a password: don't share it or post it anywhere. Only tick "Remember" on your own device. If it's ever lost, delete it on that same GitHub page and make a new one.
